# Projeto Final — Estatísticas de Jogadores de Futebol

Projeto acadêmico de Estatística com análise exploratória de atributos de jogadores de futebol. O notebook aplica conceitos de probabilidade, variáveis aleatórias, distribuições, correlação, estatística descritiva, normalização, Teorema Central do Limite e intervalos de confiança.

## Conteúdo

- `Projeto Final_Equipe 4.ipynb`: notebook com as etapas, visualizações e análises do projeto.
- `requirements.txt`: dependências Python.
- `.gitignore`: exclusões para arquivos locais e credenciais.

## Dados

O notebook baixa o dataset `data-liga-premiere` usando KaggleHub e procura `fifa_players.csv` dentro da pasta baixada. A primeira execução pode exigir acesso/credenciais do Kaggle, conforme as regras do dataset. Os dados não estão incluídos neste repositório; são baixados durante a execução.

## Como executar

Recomendado: Python 3.10 ou superior.

1. Clone este repositório e entre na pasta.
2. Crie e ative um ambiente virtual.
3. Instale as dependências: `python -m pip install -r requirements.txt`.
4. Abra o notebook com Jupyter: `jupyter notebook`.
5. Execute as células em ordem.

A célula de download usa KaggleHub. Se o Kaggle solicitar autenticação, configure o acesso conforme a documentação oficial do KaggleHub e mantenha tokens/arquivos de credenciais fora do repositório.
